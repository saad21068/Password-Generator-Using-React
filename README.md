# Password Generator

A simple and stylish password generator built using React and Tailwind CSS.

## Features
- Generate strong passwords of customizable length.
- Option to include numbers and special symbols.
- One-click copy functionality.
- Responsive and modern UI.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/password-generator.git
   cd password-generator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Usage
- Adjust the password length using the slider.
- Toggle checkboxes to include numbers and symbols.
- Click the "Copy" button to copy the generated password to your clipboard.

## Technologies Used
- React
- Tailwind CSS
